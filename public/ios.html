Earth, on your iPhone.

The spacecraft view, saved moments and native sharing. Bundled Earth imagery lets you explore a recorded orbit offline.

Download the iOS projectXcode source package · iOS 16.4+ · requires a Mac with Xcode 26+. This is not an installable App Store app or signed IPA.

Run your copy

  1. Unzip the download. Install Node.js 22+ and Xcode 26+.
  2. In the extracted folder, run npm ci, then npm run ios:sync.
  3. Run npm run ios:open. Choose an iPhone simulator in Xcode and press Run.
  4. For a real iPhone, select your Apple team under Signing & Capabilities. The included IOS.md explains device testing and distribution.

What’s inside

First-person Earth rendering, nine real spacecraft records, saved views with their original orbital elements, a system share sheet, and an offline historical recording. New orbital data and NASA imagery need a connection.

The source and browser layout are checked. Native compilation and simulator/device testing remain pending. Rendered views are simulations; NASA images are dated, not live spacecraft video.
